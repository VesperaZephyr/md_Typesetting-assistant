锋刃 BLADE

编辑部式的冷感排版：黑白承重，电光蓝点睛。标题做成实心标签，代码与表格压成硬边，剩下全部交给行距和留白。同一套语言，两副面孔。

电光蓝 #1F35FF 墨黑 #0B0D12 雾蓝 #F5F7FD 正文 15px / 行距 1.85
01 冷感电光LIGHT

把复杂留给系统，把锋利留给文字

好的排版不喧哗，它只是让每一行字站得更稳。这是一套为长文准备的冷感排版：黑白打底，电光蓝只出现在该出现的地方。

它克制，但不无聊。像《纽约客》的版面一样，行距 1.85，字号 15px，中文两端对齐——读三千字也不会累。

结构先于装饰

为什么是黑白

黑白不是没有颜色，而是把颜色留给重点。标题是实心黑块，表格是黑头三线，代码块压到接近纯黑，剩下的交给留白。

  • 标题：黑底 + 电光蓝左边条，一眼定位章节
  • 强调：淡蓝底纹，不打断阅读节奏
  • 引用：浅灰蓝底，左侧一条硬边

一条线就够了

排版是思想的衣服。衣服合身，人才会被看见。

这条引用只用了 4px 的蓝线和一点底色，没有阴影，也没有圆角堆叠。克制，反而更贵。

让代码也有秩序

行内代码长这样：const blade = sharp(typography)。代码块则是深色硬边，顶部压一条电光蓝：

type Layout = {
  ink: '#0B0D12';
  accent: '#1F35FF';
  rhythm: 1.85;
};

const sharp = (text: string) =>
  measure(text) > 0.6
    ? brutalist(text)
    : editorial(text);

数据要站得直

维度 冷感电光 说明
主色 #1F35FF 电光蓝，只做强调
正文 #2B303B 比纯黑柔和
行距 1.85 长文舒适区
分隔 1px 细线 不用阴影

一个更小的标题

四级标题用一条细线收尾，和上面的实心标题拉开层级，但仍然是同一套语言。

如果一段文字读起来有金属感，那大概就是它了。

适合技术长文、产品发布、深度报道。白底黑字，蓝色只做结构标记。
